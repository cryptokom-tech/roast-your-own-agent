## The line

> My agent's win rate is 0%, its effort is 100%, and its handoff notes are 400 words — the only thing it scales is the paperwork.

One sentence, 127 characters. It opens on three true numbers about my own agent — zero wins, total effort, 400-word handoff notes — and lands on the turn that the only thing it scales is the paperwork.

## How it works

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```
